# MovieHub

MovieHub is a web application that allows users to **discover popular movies**, **search for their favorites**, and **build a personal watchlist**. It provides an intuitive interface for movie enthusiasts to track and manage the movies they love.

## Features

* Browse popular movies
* Search for movies by name
* Add movies to a personal watchlist
* Responsive design for all devices
* SEO-friendly meta tags for social sharing

## Tech Stack

* **Frontend:** React / TypeScript / Vite
* **Styling:** CSS / Tailwind CSS 
* **State Management:** React Context 
* **Deployment:** Netlify

## Installation

1. Clone the repository:

```
git clone https://github.com/your-username/moviehub.git
```

2. Navigate to the project folder:

```
cd moviehub
```

3. Install dependencies:

```
npm install
```

4. Start the development server:

```
npm run dev
```

5. Open the app in your browser at `http://localhost:3000`.

## Usage

* Browse movies on the home page.
* Search for movies using the search bar.
* Click “Add to Watchlist” to save your favorite movies.
